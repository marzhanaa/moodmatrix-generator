# 🎨 MoodMatrix — AI Video Shot-Moodboard & Style Matrix

> A lightweight, client-side web utility built for AI video creators, directors, and prompt-engineers to instantly generate cohesive visual moodboards, compositional preview frames, color palettes, and structured multi-shot prompts.

---

---

## ✨ Key Features

- **Dynamic Genre & Vibe Switching:** Instantly reconfigures the moodboard across *Cyberpunk, Neo-Noir, 90s Anime, Sci-Fi Dystopia,* and *Vintage Documentary* presets.
- **Procedural Visual Frames:** Generates clean, vector-based compositional preview cards (Wide Establishing, Medium Character, Extreme Close-Up, Dynamic Action) tailored to the selected genre.
- **One-Click HEX & Prompt Extraction:** Instantly copy exact color palette hex codes or fully compiled prompts optimized for modern AI video models (Runway Gen-3, Kling, Sora, etc.).
- **Director's Style Bible Export:** Compiles the entire session into a structured markdown/text format for pre-production pipelines.
- **Zero-Backend / Local-First:** Runs entirely in the browser with zero external database overhead.

---

## 🛠 Tech Stack

- **Frontend:** HTML5, Vanilla JavaScript (ES6+)
- **Styling & UI:** Tailwind CSS (Custom Dark Mode configuration)
- **Graphics:** Procedural SVG generation
- **State & Storage:** Browser LocalStorage API
